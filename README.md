# achadelo.com.br

Site da marca Achadelo — achadinhos de casa e cozinha.

Este repositório é **gerado**: o conteúdo vem da pasta `site/` do repositório privado
`arthursc1/achadelo`, que é a fonte de verdade da marca (identidade, templates e decisões).
Publicado por GitHub Pages no domínio `achadelo.com.br`.

- `index.html` — vitrine, com filtro por categoria
- `oferta.html?id=…` — página de uma oferta
- `aviso.html` — como funciona o link de afiliado
- `dados/ofertas.json` — as ofertas
